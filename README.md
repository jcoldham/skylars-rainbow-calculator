# 🌈 Skylar's Rainbow Calculator

A bright, kid-friendly calculator. Number keys play musical notes, buttons squish and sparkle when pressed, a cartoon face reacts as you type, and pressing **=** sets off confetti.

**▶ Try it live: https://jcoldham.github.io/skylars-rainbow-calculator/**

## How to use it

Open the live link above on any phone, tablet or computer. Or, from a copy of this folder, double-click `index.html` to open it in a web browser. You don't need to install anything.

- Click the buttons or use the keyboard: number keys, `+ - * /`, **Enter** for =, **Backspace** to delete, **Esc** to clear.
- The 🔊 button in the corner turns the sound on and off.
- If Windows has "reduce motion" turned on, the animations turn off.

## Running the tests

Open [the online test page](https://jcoldham.github.io/skylars-rainbow-calculator/tests.html), or double-click `tests.html`. A green bar means every test passed. If any test fails, it's listed in red with what went wrong.

## What's in the folder

| File | What it does |
|------|--------------|
| `index.html` | The app: layout, colors, sounds and animations |
| `calc.js` | The calculator's math and key-press rules, shared by the app and the tests |
| `tests.html` | Unit tests for `calc.js` |
| `.claude/` | A helper that lets Claude preview the app. You don't need it to use the app. |
